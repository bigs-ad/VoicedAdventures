# v0.1.1

- 压缩包根目录新增“使用说明.txt”，面向玩家说明安装、启动、三种音源和常见问题。
- 插件目录改为“正式服与无限服”和“水豚服”，不再使用含糊的客户端分类名称。
- 明确其他怀旧服暂未适配。此次仅调整说明、发布目录名称和版本标识，不改变朗读功能。
- 保留 v0.1.0 历史发布，不覆盖原下载文件和校验值。

## v0.1.0 初始版本

首个精简公开版本。初始 Git 提交信息为 `init`。

## 发布范围

- 音源仅有系统语音、腾讯云、千问。
- 游戏内保留播放、停止、设置三个按钮，移除“未收录”及语音包覆盖判断。
- 不包含任何预录制语音包相关功能、素材、批量制作或导入工具。
- 保留实时合成与会话缓存，不积累个人语音包。
- 不发布个人凭据、账号专属音色、历史日志或旧实验中的第三方 NPC 数据库。

## 验证边界

已通过源码发布审计、现代/旧式插件 Lua 回归、C# 通信解码、连接生命周期、朗读队列、会话缓存、凭据隔离、音源持久化和千问离线协议测试。旧测试版遗留的混合音源和账号专属音色配置会安全回退或清理，避免继续引用不能共享的音色。

构建依赖使用官方 NuGet/npm 独立还原。发布 ZIP 使用明确文件白名单，内含 `SHA256.json`；打包时验证每个文件的哈希，并对解压后的助手执行隔离 UI 和系统语音组件检查。

本次不使用真实云端凭据，不进行收费合成，不修改用户的游戏安装目录。离线测试不能证明云端服务的实时可用性、用户额度、全部客户端或第二台电脑兼容性。

千问 API Key 会在本机加密保存；首次使用或重启后，若发送同意未勾选，请重新勾选再播放。没有同意时不会为缓存未命中的文本发起云端合成。

玩家首次使用时，请先验证系统语音和游戏播放/停止，再用短文本验证自己的腾讯云、千问账号。未签名程序可能触发系统安全提示，请核对下载来源和 SHA256，不要关闭防护。
