冒险有声 · 使用说明
版本：v0.1.1

一、先把压缩包完整解压

不要在压缩包里面直接运行，也不要只把一个 EXE 拖出来。
保留 Assistant 文件夹中的所有文件。

二、按照你玩的服务器安装插件

先退出游戏，每个客户端只安装对应的一份插件。

正式服：
  打开本包的“正式服与无限服”文件夹，再打开 AddOns。
  把里面的 VoicedAdventures 文件夹复制到：
  你的魔兽世界目录\_retail_\Interface\AddOns\

无限服：
  同样打开本包的“正式服与无限服”文件夹，再打开 AddOns。
  把里面的 VoicedAdventures 文件夹复制到：
  你的魔兽世界目录\_classic_beta_\Interface\AddOns\

水豚服：
  打开本包的“水豚服”文件夹，再打开 AddOns。
  把里面的 VoicedAdventures 文件夹复制到：
  你的水豚服游戏目录\Interface\AddOns\

安装后，游戏的 Interface\AddOns\VoicedAdventures 文件夹内
应该直接看到 VoicedAdventures.toc、Main.lua 和 Sounds 文件夹，
不要变成 VoicedAdventures\VoicedAdventures 的双层目录。
如果装过旧版，先备份并移走旧的同名插件文件夹，再放新版。
不要删除其他插件。其他怀旧服目前暂未适配。

三、打开助手，再进入游戏

电脑需要 Windows 64 位和 .NET 9 Desktop Runtime x64
（9.0.13 或更新的 9.0 补丁版本）。
双击 Assistant 文件夹里的 VoicedAdventures.exe。
正常双击即可，不要以管理员身份运行整个助手。
游戏接收器需要权限时会单独弹出 Windows 确认窗口。

进入游戏，在插件列表中启用“冒险有声”，玩游戏时保持助手打开。
助手发现多个游戏窗口时，请在主页选择本次要配音的客户端。

四、开始朗读

默认使用系统语音，不需要 API Key，但电脑要有 Windows 中文语音。
打开 NPC 对话或任务详情，点击旁边的播放按钮即可朗读。
三个按钮分别是：播放、停止、设置。
停止只停止声音，不断开助手连接。

也可以在游戏聊天框输入：
  /va       打开设置
  /va play  播放当前 NPC 对话（任务日志请点击窗口旁的播放按钮）
  /va stop  停止朗读

自动朗读、语速和音量，在游戏设置中调整。
正式服与无限服还可在游戏设置中选择新对话打断或排队。
音源和云端凭据，在桌面助手的“音源”页设置。

五、使用腾讯云或千问（可选）

腾讯云：在“音源”页选择腾讯云，填写自己的 AppId、SecretId、SecretKey。
千问：在“音源”页选择阿里千问，填写自己的百炼北京地域 API Key。

使用云端前，需要勾选同意发送台词并使用语音额度。
没有勾选时，不会为新内容调用云端合成。
云端服务可能收费，费用由你自己的云服务账号承担。
建议先用一小段文字试听，确认账号、声音和额度正常。
重启后如果发送同意没有勾选，请重新确认。

密钥仅在当前 Windows 用户下加密保存。不要把密钥发给别人，
不要分享个人配置目录；分享日志前也请检查是否有私人内容。

六、常见问题

助手打不开：
  确认压缩包完整解压，并安装了 .NET 9 Desktop Runtime x64。
  需要的是“桌面运行时”，不需要安装开发用的 SDK。

游戏里没有插件或按钮：
  核对服务器目录、插件文件夹层级及插件启用状态。
  安装或升级后，完整退出并重新启动游戏。

没有声音：
  检查扬声器、系统音量，以及助手是否连接到正确的游戏。
  系统语音需要 Windows 中文语音；云端音源需要有效凭据和发送同意。
  助手“日志”页可以查看错误提示。

为什么有 Sounds 文件夹：
  里面是插件通信需要的静音文件，不是预录制语音包，请不要删除。
  本版没有语音包下载、导入或本地预录制台词功能。

系统出现安全提示：
  本程序未进行代码签名。请核对仓库下载来源，不要关闭系统防护。
