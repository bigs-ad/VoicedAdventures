# 冒险有声 · Voiced Adventures

为游戏任务和 NPC 对话提供朗读的 Windows 桌面助手与游戏插件。`v0.1.0` 是首个精简发布版本。

## 下载与安装

在 [Releases](https://github.com/bigs-ad/VoicedAdventures/releases) 下载 Windows 压缩包，完整解压，不要直接在压缩包内运行。

1. 退出游戏：现代客户端使用压缩包的 `Modern/AddOns/VoicedAdventures`，Turtle 旧版客户端使用 `Turtle/AddOns/VoicedAdventures`。将对应的文件夹放入游戏的 `Interface/AddOns`，不要同时安装两份。升级测试版时先备份并移走旧的同名插件目录，避免残留文件混入；不要删除其他插件。
2. 安装 Windows x64 .NET 9 Desktop Runtime（9.0.13 或更新的 9.0 补丁版本），并确保系统有可用的中文语音。桌面助手还使用 Windows 自带的 .NET Framework 4.x 语音组件。
3. 正常双击 `Assistant/VoicedAdventures.exe`，不要以管理员身份运行整个助手。游戏接收器需要时会单独请求 Windows 权限。
4. 在游戏中启用插件，点击对话窗口旁的播放按钮，或输入 `/va` 打开设置。停止按钮仅停止朗读，不断开连接。

默认使用系统语音，不需要云端账号。游戏内保留播放、停止、设置三个按钮；没有语音包覆盖提示。

## 三种音源

| 音源 | 配置 | 网络 |
| --- | --- | --- |
| 系统语音 | Windows 已安装的中文声音 | 合成不联网 |
| 腾讯云 | 自己的 AppId、SecretId、SecretKey | 向腾讯云发送待朗读文本 |
| 千问 | 阿里云百炼北京地域 API Key | 向阿里云发送待朗读文本 |

在助手的“音源”页选择服务并填写凭据；使用云端前须勾选发送同意。云端服务可能收费，由用户自己的账号承担。工具不提供额度、不控制云端账单，也不自动重试失败的合成。

千问采用官方内置音色，不依赖作者账号的克隆音色。模型与音色依据 [阿里云官方音色列表](https://www.alibabacloud.com/help/en/model-studio/qwen-tts-voice-list) 配置。系统声音数量取决于电脑；未知 NPC 身份保留未知，不承诺为所有角色匹配专属音色。

## 范围与隐私

- 保留手动播放、自动朗读设置、语速和音量设置、停止、排队或打断、会话记录和重播。
- 不包含预录制语音包、下载或导入语音包、本地模型、个人语音包积累或混合音源回退。
- 插件 `Sounds/` 中的 WAV 是构建脚本生成的全静音通信载体，不包含人声或预录制台词，请勿删除。
- 本次运行中完整合成的音频可用于缓存重播；缓存不是可分发语音包。下次启动在取得独占锁后清理所属旧缓存，保留凭据与偏好。
- 云端凭据通过 Windows 当前用户加密保存，不写入插件和发布包。不要共享个人配置目录、API Key 或含私人内容的日志。
- 日志会遮蔽已知密钥，但可能包含任务文本、角色名称与诊断信息；分享前请自行检查。
- 不包含旧实验中的第三方任务/NPC 数据库、录音素材、私人音色目录或个人游戏数据。

## 兼容性与限制

本项目包含现代客户端和旧版 Turtle 兼容路径。不同客户端、扩展插件、系统权限和安全软件可能影响连接；保留兼容代码不等于所有客户端版本均已实机验证。

本次发布执行离线自动化与构建检查，不将其冒充为真实游戏或云端付费端到端验收。使用前应先验证系统语音，再以短文本测试自己的云服务。具体结果见 [发布说明](docs/RELEASE-NOTES.md)。

程序未进行代码签名。请仅从本仓库下载并核对校验值，不要关闭系统防护。插件是第三方项目，与游戏运营方及云服务商没有隶属关系。

## 开发

需要 Windows x64、PowerShell 7、Node.js/npm、.NET 9 Desktop Runtime，以及 Windows .NET Framework 4.x 编译器。

```powershell
npm ci --ignore-scripts
pwsh -File scripts/build.ps1
pwsh -File scripts/package.ps1
```

首次构建从官方 NuGet 下载固定版本依赖并校验哈希。`build/`、`artifacts/`、`node_modules/` 不进入源码提交。打包使用文件白名单，不读取用户的云端凭据或游戏安装目录。

源码沿用现有 `experiments/` 路径以减少无关改动，但仓库仅包含当前发布所需代码和测试，不是整个历史实验目录的镜像。
